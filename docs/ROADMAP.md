# Roadmap

These are proposals, not delivered capabilities.

- Replace calculator evaluation with a bounded arithmetic parser and cover resource limits.
- Define explicit unsupported-task and tool-error statuses for the deterministic dispatcher.
- Add validated element boxes and ambiguity handling to simulated UI actions.
- Add task-board serialization with schema validation and round-trip tests.
- Evaluate retrieval on a small published fixture set before making quality claims.
- Consider an optional model adapter only after defining interfaces, privacy boundaries and offline tests.

A release should include reproducible setup, passing checks, a changelog and clear compatibility notes. User counts, downloads and downstream use should be documented only when verifiable evidence exists.
