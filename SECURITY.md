# Security

This repository is an educational prototype, without a production support commitment.

For a sensitive issue, email huutrong748@gmail.com with the affected commit, reproduction steps and impact. Do not include live credentials or exploit unrelated services. Please avoid publishing exploitable details in an issue before the maintainer can review them.

There is no guaranteed response time. Use the latest main branch when reproducing an issue.

Known boundaries:
- The calculator uses restricted evaluation, not a hardened resource-limited sandbox.
- UI actions are simulations and do not authorize real computer interaction.
- Handoff verification flags are supplied by the caller.
- No credential storage, authentication or remote execution service is provided.
