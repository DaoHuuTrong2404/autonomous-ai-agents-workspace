## 📌 Introduction
This repository explores architectures, frameworks, and implementations of **Autonomous AI Agents**, Computer-Use Agents (CUA), and LLM-assisted workflow automation. Developed as an ongoing personal research and coursework project at Can Tho University.

## 🌟 Key Research Pillars
1. **Agentic Workflows:** Multi-agent collaboration, planning, self-reflection, and tool-use protocols.
2. **Computer-Use Agents (CUA):** Vision-based UI interaction and desktop automation.
3. **Local AI Sovereignty:** Edge computing, lightweight offline LLMs (Qwen, DeepSeek), and low-latency inference.
4. **Knowledge Management:** RAG (Retrieval-Augmented Generation) and structured personal second-brain pipelines.

## 🛠️ Technology Stack
- **Languages:** Python 3.11+, TypeScript, Node.js
- **Frameworks & Libraries:** PyTorch, Transformers, LangChain / LlamaIndex principles
- **Infrastructure:** Docker, Git, CLI automation tools
